> 对应 `docs/医疗器材合规优化方向.md` **第五章「软件安全分级」**、**第三梯队第 11 项**。
>
> **免责声明**：本文是**工程自查文件**，用于说明本项目在 IEC 62304 语境下的分级推理过程，
> **不构成任何法规符合性认定**。真实产品的定级须由制造商的质量体系（ISO 13485）与
> 风险管理流程（ISO 14971）正式输出，并经法规事务部门评审。

## 1. 定级方法与结论

IEC 62304:2006+A1:2015 第 4.3 条按**软件失效可能导致的危害严重度**分三级：

| 级别 | 定义 | 本项目判断 |
|------|------|-----------|
| **A** | 不可能导致危害，或危害不可能造成伤害 | ✗ 不适用 |
| **B** | 可能造成**非严重**伤害 | ✗ 不适用 |
| **C** | 可能导致**死亡或严重伤害** | ✓ **本项目所属类别** |

### 1.1 推定结论

**若本项目作为真实多参数监护仪的上位机软件投放市场，应定为 C 级。**

推理链：

1. 监护仪的核心功能是**报警**。报警失效（漏报 / 延迟 / 被误静音）会直接导致
   医护人员未能及时处置心动过缓、低氧血症、呼吸暂停等危及生命的事件。
2. 《医疗器材合规优化方向》第 2.2 节记录的「告警只报一次」缺陷，即为
   典型的 C 级危害路径：持续 180 bpm 的心率在首次报警后不再提示。
3. 因此软件中承担「采集 → 判定 → 报警」链路的组件（`VitalSignSimulator` 的生产逻辑、
   `AlarmDetector`、`AlarmBanner`、`MainWindow::onFrameReady`）均属 C 级组件。

### 1.2 当前项目的实际定位

| 维度 | 事实 |
|------|------|
| 数据源 | 内置模拟器，**不接入任何真实传感器** |
| 使用场景 | 学习、技术演示、作品集展示 |
| 投放状态 | **未作为医疗器械投放市场**，不适用 IEC 62304 强制要求 |
| 因此 | 本项目按 **IEC 62304 的工程实践**组织代码与过程文件，但**不声明合规** |

> 结论：**工程上按 C 级要求设计与记录，法律上不构成医疗器械。**
> 这一区分必须写清楚 —— 否则「有分级声明」反而会被误读为「已合规」。

## 2. 组件级分级

| 组件 | 文件 | 级别 | 理由 |
|------|------|------|------|
| 采样生产 | `src/data/VitalSignSimulator.cpp` | C | 数据源失效 → 全链路无效 |
| 告警判定 | `src/core/AlarmDetector.cpp` | **C** | 直接决定是否报警 |
| 告警呈现 | `src/ui/AlarmBanner.cpp` | **C** | 声光报警失效 = 危害 |
| 帧调度 | `src/ui/MainWindow.cpp`（`onFrameReady`） | C | 断链导致不报警 |
| 配置管理 | `src/core/ChannelConfig.cpp` | **C** | 阈值错误 → 误报 / 漏报 |
| 历史回放 | `src/core/HistoryRecorder.cpp` | B | 影响复查准确性，不实时危及生命 |
| 审计日志 | `src/core/AuditLogger.cpp` | B | 合规追溯，非实时安全功能 |
| 绘图 | `src/chart/TrendChartWidget.cpp` | B | 视觉呈现，数值另有数字显示 |
| 坐标映射 | `src/core/CoordinateMapper.cpp` | B | 仅影响图形坐标 |
| 环形缓冲 | `src/core/RingBuffer.h` | B | 容量固定，失效影响历史而非实时报警 |
| 文件完整性 | `src/core/FileIntegrity.cpp` | B | 数据真实性 |
| 权限 | `src/core/UserRole.cpp` | B | 防误用 |
| 自检 | `src/core/SelfTest.cpp` | B | 可用性判断 |

## 4. 已知残余差距（诚实清单）

以下差距**无法通过写代码填补**，必须由组织级质量体系完成：

1. **无正式的软件安全分级评审记录**（本文只是工程师自查）。
2. **无临床验证**：所有阈值（如 HR 高限 110 bpm）来自教科书常识，
   未经临床专家评审，也未做过成人 / 小儿 / 新生儿的分层验证。
3. **无真实数据链路**：没有传感器驱动、没有信号调理、没有导联脱落真实检测。
4. **无系统级测试**：没有 7×24 小时稳定性测试、没有断电恢复测试。
5. **无可用性测试**：IEC 62366-1 要求的形成性 / 总结性评价均未开展。
